# 產品需求文件 (PRD)

## 1. 專案概述
- **背景與動機**：需要一個簡單快速的平台，讓主辦方可以輕鬆建立活動，讓使用者透過專屬連結即可快速報名，並且能夠即時統計報名狀況。
- **目標用戶**：任何擁有此連結的人（包含發起活動的主辦方與收到連結的報名者）。
- **核心價值主張**：無須繁雜的登入或註冊流程，一鍵分享連結即可收集報名資訊；主辦方能輕鬆掌握報名總數及男女比例，方便後續籌備。

## 2. 功能需求
為滿足系統目標，預計開發以下 5 項主要功能：

1. **建立活動**
   - 作為主辦方，我希望能夠建立一個新的報名活動（填寫活動名稱、時間、簡介等），以便產生一組專屬的活動報名連結。
2. **填寫報名資料**
   - 作為報名者，我希望能透過活動連結開啟表單並填寫基本資料（包含性別），以便快速完成活動報名。
3. **計算報名人數**
   - 作為主辦方，我希望能夠即時查看目前的已報名總人數，以便控管活動規模與報名進度。
4. **性別資料統計 (分男女)**
   - 作為主辦方，我希望系統能在資料後台自動加總報名者的男女性別數量，以便進行後續的活動分組或物資準備。
5. **報名名單檢視與匯出**
   - 作為主辦方，我希望能在專屬的檢視頁面查看完整的報名明細清單，並支援簡單的清單複製或匯出，以便活動當天進行報到與聯絡。

## 3. 非功能需求
- **技術限制**：後端採用 Python Flask 框架，前端網頁使用 Jinja2 模板實作，資料庫使用結構單純的 SQLite。
- **效能與操作考量**：頁面響應時間與載入速度需迅速，盡可能以直覺的 UI 讓首次使用的參與者也能在 1 分鐘內完成報名。
- **安全考量**：送出報名表單需有基本的資料驗證與防護（如防止 SQL Injection 及 XSS），未公開連結或報名清單頁面應有基礎保護。

## 4. MVP 範圍

### Must Have (必須具備的 MVP 核心)
- 建立活動頁面並產生網址
- 供報名者填寫的報名頁面（含性別選單）
- 主辦方檢視頁面，能顯示「總人數」、「男生總數」、「女生總數」及「報名清單」

### Should Have (第二階段功能)
- 報名人數上限機制，以及額滿時鎖定報名的功能
- 表單欄位必填與格式驗證機制

### Nice to Have (未來優化項目)
- 將報名單一鍵匯出成 CSV / Excel 檔
- 主辦方管理後台（支援編輯活動或刪除錯誤報名）
- 給報名者的報名成功確認提示視窗或自動寄發信件
