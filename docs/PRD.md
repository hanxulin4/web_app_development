# 產品需求文件（PRD）— 活動報名系統

## 1. 專案概述

### 1.1 背景與動機

在日常生活中，無論是社團、班級或朋友之間，經常需要舉辦各種活動（聚餐、出遊、運動等）。傳統的報名方式（如 LINE 接龍）容易造成統計混亂、遺漏人數、無法區分性別等問題。本系統旨在提供一個簡潔的線上活動報名平台，讓活動主辦者能快速建立活動，參加者只需透過連結即可報名，系統自動統計總人數與男女人數。

### 1.2 目標用戶

- **所有擁有連結的人**：任何人只要取得活動連結，即可瀏覽活動資訊並報名參加。
- 不需要帳號登入機制，降低使用門檻。

### 1.3 核心價值主張

- **簡單易用**：透過連結即可報名，無需註冊或登入。
- **即時統計**：自動計算總報名人數、男性人數、女性人數。
- **快速建立**：活動主辦者可在幾秒內建立一個新活動。

## 2. 功能需求

### 2.1 建立活動

> 作為**活動主辦者**，我希望**建立一個新活動（填寫活動名稱與活動日期）**，以便**讓其他人可以報名參加**。

- 填寫活動名稱（必填）
- 選擇活動日期（必填）
- 可選填活動描述
- 建立成功後產生專屬的活動報名連結

### 2.2 報名活動

> 作為**參加者**，我希望**透過連結進入活動頁面並填寫報名資料**，以便**完成報名**。

- 填寫姓名（必填）
- 選擇性別：男 / 女（必填）
- 可選填聯絡資訊（如電話或 Email）
- 提交報名後顯示成功訊息

### 2.3 計算總人數

> 作為**活動主辦者**，我希望**即時看到目前的報名總人數**，以便**掌握活動參加情況**。

- 在活動頁面即時顯示目前報名總人數
- 每次有人報名後自動更新

### 2.4 男女人數統計

> 作為**活動主辦者**，我希望**看到報名者的男女比例與人數**，以便**做活動準備（如分組、餐點等）**。

- 在活動頁面分別顯示男性人數與女性人數
- 以視覺化方式呈現男女比例

### 2.5 顯示活動資訊

> 作為**報名者**，我希望**在報名前看到活動名稱、日期等基本資訊**，以便**決定是否參加**。

- 顯示活動名稱
- 顯示活動日期
- 顯示活動描述（若有）
- 顯示目前報名人數

### 2.6 活動列表（首頁）

> 作為**使用者**，我希望**在首頁看到所有活動的列表**，以便**快速瀏覽與選擇活動**。

- 列出所有活動（名稱、日期、報名人數）
- 可點擊進入個別活動頁面
- 按日期排序顯示

### 2.7 報名名單查看

> 作為**活動主辦者**，我希望**查看完整的報名名單**，以便**掌握誰已經報名**。

- 顯示所有報名者的姓名與性別
- 顯示報名時間

## 3. 非功能需求

### 3.1 技術限制

| 項目     | 技術選型              |
| -------- | --------------------- |
| 後端框架 | Flask (Python)        |
| 模板引擎 | Jinja2                |
| 資料庫   | SQLite                |
| 前端     | HTML + CSS + 基本 JS  |

### 3.2 效能考量

- 系統為小型應用，預期同時使用人數不超過 50 人
- SQLite 足以應付預期的資料量
- 頁面載入時間應在 2 秒以內

### 3.3 安全考量

- 表單輸入需做基本驗證（防空白、防 XSS）
- 使用 CSRF token 保護表單提交
- 不需要帳號系統，但活動建立頁面可考慮簡單的存取控制

### 3.4 可用性

- 介面需支援手機瀏覽（Responsive Design）
- 操作流程簡潔，報名不超過 3 個步驟
- 使用繁體中文介面
